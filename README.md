# Landscape Image Classification with CNNs

## Overview
This project uses Convolutional Neural Networks (CNNs) to classify landscape images into different scene categories.

## Technologies
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-Learn

## Deep Learning Techniques
- Convolutional Neural Networks (CNN)
- LeNet-5 Architecture
- Dropout Regularization
- Data Normalization
- Model Evaluation

## Evaluation Metrics
- Accuracy
- F1 Score
- Confusion Matrix

## Experiments
- Baseline LeNet-5
- Modified CNN Architectures
- Robustness Testing
- Architecture Comparison

## Dataset
Intel Image Classification Dataset
